## Best practices implementation
- Servir la file initiale d'exceptions depuis un Server Component, et reserver les mutations d'assignation / resolution a des Server Actions authentifiees.
- Indexer les colonnes `project_id`, `owner_user_id`, `status` et les FK de file, avec index partiels sur les exceptions `open` et `awaiting_validation` pour les vues prioritaires.
- Utiliser une pagination par curseur pour les listes longues, et conserver `tab`, `owner` et `severity` dans les query params pour rendre la revue partageable.
- Passer filtres, tri et ouverture de la sheet d'assignation en `startTransition`, en evitant d'envoyer au client le detail complet des exceptions non visibles.
- Garantir un parcours clavier complet sur la file et la sheet, avec focus visible, ordre de tabulation stable et confirmation explicite avant reassignation sensible.
