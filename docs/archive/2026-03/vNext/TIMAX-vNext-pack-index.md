# TIMAX vNext — Pack documentaire

Ce pack contient :

1. `README.md`
   - vue d'ensemble vNext
   - index des epics
   - ordre de lancement recommande

2. `IMPLEMENTATION_PLAN.md`
   - plan d'implementation optimise pour 2 equipes
   - ownership
   - vagues
   - hotspots de collision

3. `SEQUENCING_2_TEAMS.md`
   - sequencing court et executable
   - dependances
   - zones a posseder par equipe

4. `VNEXT-E01` a `VNEXT-E06`
   - un fichier par epic
   - objectif
   - stories
   - criteres transverses
   - zones de code probables

5. `TEAM-A-AGENT-PROMPT.md` et `TEAM-B-AGENT-PROMPT.md`
   - prompts d'execution pour lancer les equipes

6. `TIMAX-vNext-backlog-structure.md`
   - vision vNext
   - principes UX et métier
   - epics
   - user stories
   - critères d’acceptation
   - releases
   - revue MECE et anti-oubli

7. `TIMAX-vNext-decisions-risques.md`
   - décisions produit pour réduire le risque au minimum
   - réponses recommandées aux questions ouvertes
   - garde-fous anti-risque
   - checklist de lancement

Rappel de lecture :
- le **flux principal** reste `affaire -> intake -> brief -> import DPGF tabulaire -> mapping -> création de version -> sync plans -> takeoff IA -> review/apply -> suggestions de prix` ;
- `version-zero` et `generated-ouvrages` restent des **branches adjacentes** ;
- `takeoff estimate-first` reste du **legacy** ;
- toute proposition de vNext est marquée `[inference]`.
