## Best practices implementation
- Supabase / Postgres : indexer l'historique des actions par `project_id`, `action_type`, `created_at` pour conserver une command bar reactive et paginer l'historique au curseur si la liste grossit.
- Next.js : calculer les suggestions initiales cote serveur et declencher les actions du cockpit via Server Actions ; n'utiliser un route handler que si la commande doit etre exposee hors UI.
- Next.js / RSC : ne serialiser vers le client que l'identifiant, le libelle, l'intent et le preview court de chaque suggestion, jamais l'etat complet de l'affaire.
- React / perf : charger en dynamic import les panneaux lourds de preview si necessaire et utiliser `startTransition` pour les refresh non urgents de suggestions / filtres.
- UX / accessibilite : ouverture clavier, focus visible, navigation flechee, `aria-live` sur le refresh des suggestions et copy concise qui distingue clairement `voir`, `preparer` et `lancer`.
