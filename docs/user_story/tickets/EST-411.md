## Best practices implementation
- Stocker les retours client en journal append-only sous RLS stricte, avec index sur `project_id`, `version_id`, `thread_id`, `status`, `source_channel` et `received_at`.
- Lancer en parallele lecture des messages, detection de changements et rapprochement avec la version publiee, puis n'afficher la synthese editable qu'une fois les trois signaux recoupes.
- Servir la synthese initiale via Server Component et limiter les props client aux deltas, preuves et actions corrigeables effectivement affichees.
- Utiliser une pagination par curseur pour les fils longs et conserver la distinction visuelle entre fait detecte, hypothese IA et proposition de modification.
- Annoncer les recalculs et corrections de synthese via `aria-live`, sans bloquer la reprise manuelle ni perdre le contexte de la version analysee.
