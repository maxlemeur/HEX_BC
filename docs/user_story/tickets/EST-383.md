## Best practices implementation
- Indexer les suggestions de sous-detail sur `project_id`, `parent_work_id`, `status` et `source_fragment_id` pour garder la revue composee rapide.
- Recuperer composants, quantites candidates et sources en parallele, puis presenter un brouillon compose immutable tant qu'aucune validation humaine n'est faite.
- Garder edition, split, merge et acceptation dans des Server Actions type-safe, avec payload client limite aux lignes actuellement visibles.
- Importer dynamiquement l'editeur de sous-detail si la vue devient lourde, plutot que d'alourdir le premier rendu de l'ecran de review.
- Marquer explicitement ce qui est `suggere`, `calcule` ou `saisi manuellement`, avec libelles compréhensibles et focus conserve lors des edits inline.
