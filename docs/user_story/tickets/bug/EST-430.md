## Best practices implementation
- Centraliser la traduction entre composants de sous-detail (`material`, `labor`, `equipment`, `subcontract`) et champs metier du devis dans un contrat unique, pas dans des derivees UI dispersees.
- Eviter qu'une checklist de completude repose sur un etat incomplet de la ligne quand la source de verite est deja presente dans le sous-detail valide.
- Conserver une trace explicite du mapping applique lors de l'insertion pour debugger les cas de derive economique.
- Couvrir le correctif avec un test de non-regression bout en bout qui verifie a la fois l'insertion et l'absence de faux positif checklist.
