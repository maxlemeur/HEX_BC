## Best practices implementation
- Distinguer clairement les sources a fort signal (`DPGF`, brief confirme, notes affaire structurees) des sources a signal faible (`ouvrages` seuls, heuristiques de secours).
- Eviter de sur-produire des lots pseudo-plausibles quand le contexte est pauvre; mieux vaut peu de suggestions explicables que beaucoup de bruit.
- Utiliser la confiance pour piloter les etats UI par defaut: masquer, de-selectionner ou regrouper les suggestions faibles.
- Ajouter des fixtures de faible contexte dans les tests pour stabiliser la regression sur la pertinence metier.
