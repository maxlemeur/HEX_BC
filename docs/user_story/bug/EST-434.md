# EST-434 — Incoherence entre resume delta global et delta de ligne

> Type: Bug produit
> Epic: [EST-E23](../EST-E23-preuve-prix-risque.md)
> Ticket source: [EST-394](../tickets/EST-394.md)
> Severite: Majeure
> Priorite: P1
> Statut: A faire

## Contexte

Le panneau `Expliquer le delta` se charge bien, mais le resume global affiche un delta positif alors que la ligne explicitement identifiee comme driver principal est en baisse.

## Reproduction

1. Partir d'une version avec une ligne IA.
2. Dupliquer en V2.
3. Modifier la quantite de la ligne, par exemple `120 -> 100`.
4. Ouvrir l'ecran de comparaison `V2 vs V1`.
5. Cliquer sur `Expliquer le delta`.

## Resultat observe

- Le diff de ligne indique bien une baisse de `4 110,00 EUR HT -> 3 425,00 EUR HT`, soit `-685,00 EUR HT`.
- Le panneau delta affiche pourtant un resume global du type `hausse globale de 3 425,00 EUR HT`.
- Le detail charge tente de rationaliser l'ecart en invoquant d'autres parametres globaux potentiellement modifies.

## Resultat attendu

- Le resume global, les totaux du diff et le driver principal doivent etre coherents entre eux.
- Si une unique ligne est modifiee a la baisse, l'explication ne doit pas annoncer une hausse globale contradictoire sans preuve solide.
- Le texte detaille ne doit pas compenser un calcul incoherent par une inference speculative.

## Impact

- Perte de confiance dans la fonctionnalite d'explication.
- Risque de presenter a la direction ou au client une note de synthese contradictoire.
- Le feature passe du role d'aide a la decision a un role de rationalisation peu fiable.

## Hypotheses techniques

- Le panneau delta s'appuie sur des totaux de version non recalcules ou des snapshots desynchronises.
- L'algorithme d'explication agrege correctement le driver de ligne mais sur un resume global incoherent.
- Les donnees d'entree du diff et celles du panneau explicatif ne partagent pas exactement la meme base de calcul.

## Zones probables

- `src/app/api/estimates/[versionId]/delta-explanation/route.ts`
- `src/lib/estimates/explanations.ts`
- `src/components/estimates/EstimateDiffView.tsx`

## Definition of done

- [ ] Le resume court du delta est coherent avec les deltas de ligne affiches
- [ ] Le detail charge ne compense plus un calcul incoherent par une hypothese speculative
- [ ] Test de non-regression ajoute sur un cas simple `1 ligne modifiee`
