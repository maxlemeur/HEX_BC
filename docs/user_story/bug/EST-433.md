# EST-433 — Disparition de `Expliquer ce prix` apres duplication de version

> Type: Bug produit
> Epic: [EST-E23](../EST-E23-preuve-prix-risque.md)
> Ticket source: [EST-394](../tickets/EST-394.md)
> Severite: Majeure
> Priorite: P1
> Statut: A faire

## Contexte

Le bouton `Expliquer ce prix` est visible et fonctionnel sur une ligne IA dans la version source, mais il disparait dans la version dupliquee alors que la ligne reste presente et exploitable dans l'editeur.

## Reproduction

1. Creer un devis.
2. Inserer une ligne IA via `Generer des ouvrages`.
3. Verifier que la ligne source affiche `Expliquer ce prix`.
4. Dupliquer le devis en nouvelle version.
5. Ouvrir la version dupliquee dans l'editeur.
6. Observer la meme ligne.

## Resultat observe

- La ligne est bien presente dans la version dupliquee.
- Le bouton `Expliquer ce prix` n'est plus affiche sur cette ligne.

## Resultat attendu

- Le bouton `Expliquer ce prix` reste disponible sur la ligne dupliquee si sa provenance et ses donnees d'explication sont encore exploitables.
- A minima, le systeme doit rendre explicite pourquoi l'action n'est plus disponible.

## Impact

- Perte de continute metier entre versions.
- Le critere `Une action Expliquer ce prix existe sur chaque ligne` n'est pas defendable sur les parcours de versioning.
- La fonctionnalite semble plus liee a l'etat de la ligne source qu'a la ligne metier dupliquee.

## Hypotheses techniques

- La duplication ne preserve pas les metadonnees ou le provider necessaires a l'affichage du badge source.
- Le trigger est calcule uniquement pour certaines lignes IA d'origine et pas pour leurs copies versionnees.

## Zones probables

- `src/components/takeoff/TakeoffSourceBadge.tsx`
- `src/lib/estimates/server.ts`
- `src/app/api/estimates/[versionId]/duplicate/route.ts`

## Definition of done

- [ ] Le bouton `Expliquer ce prix` reste disponible sur la ligne dupliquee quand la provenance le permet
- [ ] Sinon, la raison d'indisponibilite est explicite et testee
- [ ] Test E2E de non-regression ajoute sur duplication + explication de prix
