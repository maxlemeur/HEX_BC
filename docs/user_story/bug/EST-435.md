# EST-435 — Impact marge insuffisamment explicite dans le panneau delta

> Type: Bug produit
> Epic: [EST-E23](../EST-E23-preuve-prix-risque.md)
> Ticket source: [EST-394](../tickets/EST-394.md)
> Severite: Mineure
> Priorite: P2
> Statut: A faire

## Contexte

Le panneau `Expliquer le delta` expose bien l'impact montant HT/TTC, mais l'impact marge n'apparait pas comme un resultat metier de premier niveau alors que c'est un critere explicite de la story.

## Reproduction

1. Ouvrir l'ecran de comparaison entre deux versions.
2. Cliquer sur `Expliquer le delta`.
3. Lire le resume court, les cartes de synthese et les sections `Faits / Hypotheses / Inferences`.

## Resultat observe

- Le panneau met clairement en avant HT/TTC.
- La marge apparait seulement comme information textuelle secondaire (`Marge actuelle`, `Marge comparee`).
- Il n'existe pas de bloc ou formulation claire de l'impact marge dans la synthese principale.

## Resultat attendu

- L'impact marge doit etre visible au meme niveau que l'impact montant lorsque l'information est disponible.
- L'utilisateur doit pouvoir expliquer rapidement si la variation touche seulement le montant, la marge, ou les deux.

## Impact

- Lecture metier incomplete pour la direction et la revue economique.
- Le critere `impact sur marge et montant` n'est que partiellement satisfait.

## Hypotheses techniques

- Le schema contient deja les champs de marge, mais le panneau ne les rend pas dans la synthese principale.
- Le produit s'arrete a un affichage technique des faits sans transformer ces donnees en lecture metier.

## Zones probables

- `src/components/estimates/EstimateExplanationPanel.tsx`
- `src/lib/estimates/explanation-schemas.ts`

## Definition of done

- [ ] Un impact marge explicite est visible dans la synthese principale quand les donnees existent
- [ ] Le resume court distingue clairement montant et marge
- [ ] Un test UI couvre le rendu de l'impact marge dans le panneau delta
